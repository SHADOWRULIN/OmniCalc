# OmniCalc 🚀

A modern, responsive Scientific & Standard Calculator web application built with vanilla HTML, Tailwind CSS, and JavaScript. Zero dependencies, no complex build steps, and designed to run directly on GitHub Pages.

---

## 🌐 Live Demo

👉 **[Try OmniCalc Live](https://shadowrulin.github.io/OmniCalc/)**

---

## ✨ Features

- 🧮 **Dual Modes**: Seamlessly switch between **Standard** mode (everyday arithmetic) and **Scientific** mode (`sin`, `cos`, `tan`, `log`, `ln`, `√`, `x^y`, `n!`, `π`, `e`).
- 📐 **Angle Units**: One-tap toggle between **Degrees (DEG)** and **Radians (RAD)**.
- 🕒 **Persistent History**: Stores past calculations in `localStorage` with quick-copy and recall functions.
- ⌨️ **Keyboard Support**:
  - `0`–`9` & `.` : Input digits
  - `+`, `-`, `*`, `/`, `%` : Arithmetic operations
  - `Enter` or `=` : Calculate result
  - `Backspace` : Delete last character
  - `Escape` : All Clear (AC)
- 💎 **Modern UI**: Clean glassmorphism styling with dark mode aesthetics powered by Tailwind CSS.

---

## 🛠️ Tech Stack

- **Markup**: HTML5
- **Styling**: Tailwind CSS & Glassmorphism effects
- **Logic**: Pure Vanilla JavaScript (ES6+)
- **Hosting**: GitHub Pages
